## Outcome

`altai-cli paperclip-spike` exists — the harness `PAPERCLIP_SPIKE_PLAN.md`
§3 calls the only way to pass. It drives the **real control-plane axum
router in-process** (production `router_with_control_repositories` wiring
over throwaway SQLite + in-memory repositories, the same shape as the
daemon's own dispatch tests) via `tower::ServiceExt::oneshot` — no
network, no daemon, no stub HTTP layer between the harness and the wire
handlers.

Phases, each a typed exit code (30–35, clear of the `run` command's
public 0–8/10 contract):

- **health (30):** `/v1/health` is bootstrap-gated (anonymous → 401) and
  reports the wire `protocol_major` the registration then uses.
- **registration (31):** bootstrap-authed grant → host register (echoed
  `agent_instance_id`) → grant replay rejected 401 (one-time).
- **fixture (32):** one Work item seeded through the wired work-graph
  repository (the control router does not serve the work-graph routes;
  plan step 2 is a precondition, not a wire step).
- **dispatch (33):** wake enqueued; a second source **coalesces into the
  same wake** with both sources present (020).
- **checkout (34):** claim stamps `claimed_at`; transactional checkout
  takes the lease.
- **reconnect (35):** executed **twice** with lease state asserted between
  runs — fresh-grant re-registration, re-claim → 409 `AlreadyClaimed`
  (no double fire), same-lease replay → 409 (idempotent reattach, owner
  unchanged), rival-owner checkout → 409 (lease not stolen), stale
  finalizer release → 409 (021), and the rightful owner's replay still
  conflicting as live holder between runs. Closes with rightful release
  → 204 and a fresh attempt checking out after recovery (023).

`--json` emits a machine-readable step report; failures print
`[phase] step: detail` and exit with the phase code.
