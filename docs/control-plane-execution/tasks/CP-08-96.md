# CP-08-96 — deterministic attempt evaluation summary

- **Package:** 091 — Evaluation, replay and quality dashboard (PR 3)
- **Status:** accepted — `efecnc/altai-app-1` PR #63 (`aefc24a0`)
- **Depends on:** 043, 045, 084 and CP-08-95

`EvaluationAttemptSummary` is a pure, read-only view over one canonical
`EvaluationReplayProjection` and exact-scope immutable `UsageRecord` facts.
It preserves the replay coverage projection and exposes lexically ordered,
checked totals per named meter. No exact-scope record is represented as
`Unavailable`, never a zero-cost or estimated claim. Foreign, partial,
duplicate, empty-meter and overflowing records fail closed.

**Evidence:** 275 control-plane tests and `cargo clippy` with warnings denied
passed locally. Fork CI passed changes, frontend, Linux/macOS/Windows Rust,
Linux/macOS/Windows CLI smoke and Amazon Q checks.
