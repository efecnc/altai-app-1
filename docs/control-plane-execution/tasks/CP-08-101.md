# CP-08-101 — durable remote-worker notification store

- **Package:** 093 — Remote workers and collaboration notifications (PR 3)
- **Status:** accepted — `efecnc/altai-app-1` PR #72 (`29908c14`)
- **Depends on:** 051, 052, CP-08-99 and CP-08-100

Persist the CP-08-100 proposal ledger into the local `work.db` without
weakening any of its invariants: proposals stay insert-only (identical
replay is a no-op, divergent replay conflicts), a delivery's scope
attribution can never be rewritten, a worker self-report stays visible
provenance that never moves delivery state, and `Delivered` remains
reachable only through the canonical acknowledgement keyed by
`delivery_id`. The store issues no credential and has no path into
Attempt state.

**Evidence:** 295 control-plane tests (including the 9 repository tests:
reopen durability, scope filtering, arrival-order claims, exactly-once ack)
and 1128 root-package tests passed locally; warnings-denied clippy on all
targets passed; full fork CI passed all 10 checks — Linux/macOS/Windows
Rust, Linux/Windows/macOS CLI smoke, frontend static/tests, changes and
Amazon Q. Independent static review verified every invariant and its 8
findings were fixed before merge.
