# CP-08-95 — comparison evidence and dashboard boundary discovery

- **Package:** 091 — Evaluation, replay and quality dashboard (PR 2)
- **Status:** ready
- **Depends on:** 045, 084 and CP-08-94

## Outcome

Define the smallest read-only dashboard input that can compare canonical
evaluation replay projections across attempts without inventing a quality-score
authority, retaining evidence payloads, or exposing a model/credential path.

## Acceptance

- Every displayed aggregate identifies the canonical Work/Attempt and replay
  schema it came from.
- Cost evidence is either a named, existing immutable ALTAI usage record or is
  explicitly unavailable; no guessed cost, provider receipt or secret-bearing
  payload is admitted.
- The discovery distinguishes read-model projection from evaluator policy,
  completion, delivery, routing and persistence authority.
- It names deterministic positive and negative fixtures before any dashboard or
  transport implementation begins.
