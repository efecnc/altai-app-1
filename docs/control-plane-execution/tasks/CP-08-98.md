# CP-08-98 — deterministic routing recommendation fixture

- **Package:** 092 — Smart routing and learning/playbooks (PR 2)
- **Status:** accepted — `efecnc/altai-app-1` PR #66 (`015adae0`)
- **Depends on:** 043, 091 and CP-08-97

`RoutingRecommendation` is a pure, read-only candidate ordering. It accepts
only same-Work candidate snapshots, preserves dispatch/budget/governance facts
as hard blockers, orders only blocker-free candidates by explicit priority then
canonical agent id, and rejects foreign Work or duplicate agents. It performs
no repository I/O, executor selection, claim, dispatch, persistence, model
call, score or learning.

**Evidence:** 277 control-plane tests and warnings-denied clippy passed locally;
full fork CI passed Linux/macOS/Windows Rust and CLI smoke, frontend and Amazon Q.
