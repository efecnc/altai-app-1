## Outcome

Implement `LH-081-recovery-evidence-v1` against the existing ALTAI real-plane
test wiring. The test interrupts the scripted worker after `Started`,
re-registers the same host through the authenticated wire, proves the original
lease and sole Attempt remain authoritative, then emits `Terminated`,
finalizes idempotently, queries the correlated Activity pair, and records one
immutable Evidence row.

No LongHorizon source or runtime is added. The benchmark is an ALTAI contract
test and establishes whether a future non-authoritative adapter boundary is
safe to consider.

## Acceptance

- The focused `altai-cli` test passes with exactly one running and one terminal
  Attempt across reattachment.
- A rival checkout and duplicate wake claim fail closed.
- Exactly the correlated Started/Terminated Activity pair is queryable and one
  immutable Evidence record is attributable to the Work/Attempt.
- Same-outcome finalization is idempotent; no external runtime is introduced.
