# CP-08-100 — deterministic remote-worker notification fixture

- **Package:** 093 — Remote workers and collaboration notifications (PR 2)
- **Status:** accepted — `efecnc/altai-app-1` PR #70 (`9205e98e`)
- **Depends on:** 051, 052 and CP-08-99

`remote_worker_notification` is a pure proposal ledger. It accepts only
scope-exact, attributed, bounded proposals from an already-authenticated
worker identity, stores them insert-only (identical replay is a no-op,
divergent replay conflicts), records worker self-reports as visible
provenance without moving delivery state, and reaches `Delivered` solely
through a canonical acknowledgement keyed by `delivery_id`. It issues no
credential, has no path into Attempt state, and performs no repository or
transport I/O.

**Evidence:** 286 control-plane tests (including the 9 new notification-fixture
tests) and warnings-denied clippy passed locally; full fork CI passed all 10
checks — Linux/macOS/Windows Rust, Linux/Windows/macOS CLI smoke, frontend
static/tests, changes and Amazon Q.
