# CP-08-99 — remote-worker credential and notification boundary discovery

- **Package:** 093 — Remote workers and collaboration notifications (PR 1)
- **Status:** in progress
- **Depends on:** 051 and 052

Identify the existing credential broker, worker isolation and durable activity
delivery seams. Define a transport-independent notification fixture where an
untrusted remote worker can propose an attributed event but cannot obtain a
credential, mutate an Attempt, or mark a notification delivered without the
canonical control-plane acknowledgement.
