# CP-08-94 — deterministic evaluation replay projection

- **Package:** 091 — Evaluation, replay and quality dashboard (PR 1)
- **Status:** accepted — `efecnc/altai-app-1` PR #60 (`36a6fd98`)
- **Depends on:** 045, 084 and CP-08-93

`EvaluationReplayProjection` derives a versioned, transport-free and
read-only coverage view from canonical `EvidenceReplayInput`: evidence and
Activity counts, unique correlation count and lexically ordered evidence kinds.
It excludes artifact references, event ids, raw correlation values, timestamps,
source text, evaluator output, scores, persistence and every mutation path.
Unsupported source schemas and empty source collections fail closed.

**Evidence:** 272 control-plane tests and `cargo clippy` with warnings denied
passed locally. Fork CI passed changes, frontend, Linux/macOS/Windows Rust,
Linux/macOS/Windows CLI smoke and Amazon Q checks.
