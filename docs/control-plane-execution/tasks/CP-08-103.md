# CP-08-103 — legacy read-only importer boundary discovery

- **Package:** 100 — Legacy read-only importers (PR 1)
- **Status:** accepted — `efecnc/altai-app-1` PR #76 (`7cfb9ee8`)
- **Depends on:** 052

Identify the legacy assignment/todo/orchestration state surfaces and define
the read-only, idempotent import boundary into canonical Work items: per
legacy surface, the record shape it owns today, the canonical entity and
stable key each record maps to, and the authority/idempotency rules that
make re-import a no-op. No new state owner, credential path or mutation
authority; the legacy stores remain the source until cutover.

**Outcome:** boundary recorded in `LEGACY_IMPORTER_DISCOVERY.md` —
assignments as the primary source, todos scoped to manual records with
named identity gaps (immutable provider ids, org/project attribution,
missing timestamps/origins) that PR 2 closes in scope, orchestration
intents and IsanAgent-owned notifications excluded with cited rationale.
Idempotency rides a dedicated mapping table on the `legacy_work_bridge`
fail-closed pattern with content-hash revision substitution.
