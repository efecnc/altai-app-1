# CP-08-104 — read-only legacy import command implementation

- **Package:** 100 — Legacy read-only importers (PR 2)
- **Status:** implemented on `feat/fork-cp08-104-legacy-import`;
  accepted when fork CI is green
- **Depends on:** CP-08-103 and 052

Build exactly one host-callable import implementation against the accepted
boundary in `LEGACY_IMPORTER_DISCOVERY.md`: a control-plane module that
reads legacy assignment/todo store JSON read-only, projects each record
into canonical Work items through a dedicated mapping table keyed on the
legacy id plus a content hash (identical re-import is a no-op, changed
content updates exactly one row, nothing is ever deleted), records legacy
statuses as provenance without translating them, closes the three named
identity gaps in scope (attribution into the default organization under an
importer-owned project; manual-only todos stamped at import time; immutable
provider ids scoped down explicitly rather than invented), and reports
typed counts/errors. The public versioned protocol contract is not extended
by a migration tool.
