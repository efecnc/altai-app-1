# CP-08-92 — repository readiness and bounded context-pack discovery

- **Package:** 090 — Repository readiness and context-pack builder (PR 1)
- **Status:** in progress
- **Depends on:** 031, 045 and CP-08-91

## Outcome

Inventory current repository scope, run-context and evidence paths, then
define a bounded context-pack fixture that references canonical ALTAI state
without copying it into a new repository/session store.

## Acceptance

- Every candidate input has a named canonical owner and scope check.
- The fixture measures requested versus admitted context bytes and rejects
  ungranted repositories, foreign scope and secret-like inputs.
- No new workspace identity, credential path or durable context database is
  introduced by this discovery task.
