# CP-08-103 — legacy read-only importer boundary discovery

- **Package:** 100 — Legacy read-only importers (PR 1)
- **Status:** implemented on `docs/fork-cp08-103-importer-discovery`;
  accepted when fork CI is green
- **Depends on:** 052

Identify the legacy assignment/todo/orchestration state surfaces and define
the read-only, idempotent import boundary into canonical Work items: per
legacy surface, the record shape it owns today, the canonical entity and
stable key each record maps to, and the authority/idempotency rules that
make re-import a no-op. No new state owner, credential path or mutation
authority; the legacy stores remain the source until cutover.
