# CP-08-88 — OpenTag provenance and identity conformance discovery

- **Package:** 083 — OpenTag codebase (PR 1)
- **Status:** accepted — `altaidevorg/altai-app` PR #837 (merge
  `80ae55e0`, 2026-08-20) recorded the pinned source, ownership decision and
  deterministic fixture; package 083 remains in progress for CP-08-89
- **Depends on:** 051 (versioned protocol framing), 071 (plugin boundaries),
  and CP-08-87 (the preceding ordered adoption-track decision)

## Outcome

Identify and pin the authoritative OpenTag source, revision, license and
history. Inventory only tag/metadata mechanisms that could improve ALTAI
without creating a second identity, authorization, or plugin registry. Map
each candidate to ALTAI's versioned protocol and existing ownership boundary,
then publish an explicit adopt/defer/reject decision.

## Scope

- Reproducible provenance and license record for every inspected source.
- A concept matrix for tag identity, metadata schema, attachment/scoping,
  mutation authority, synchronization and query behavior.
- Conformance fixtures that prove one canonical identity and one authoritative
  mutation path across protocol and plugin boundaries.
- No vendored source, new tag database, parallel identity registry, or runtime
  integration in this discovery task.

The source inventory, decision matrix, and `OT-083-identity-metadata-v1`
fixture are recorded in `OPENTAG_CONFORMANCE_DISCOVERY.md`.

## Evidence

- The authoritative repository, immutable revision and MIT license blob are
  recorded in the discovery decision.
- Every inspected OpenTag concept has an explicit canonical ALTAI boundary or
  a direct-adoption rejection.
- PR #837 passed its required changes and frontend CI checks before merge.

## Acceptance

- Each candidate either maps to a specific existing ALTAI contract or is
  rejected with the ownership conflict stated.
- The proposed benchmark has deterministic fixtures and pass/fail observations.
- A reviewed decision bounds any follow-up code to an adapter rather than a
  new system of record.
