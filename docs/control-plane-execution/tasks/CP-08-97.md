# CP-08-97 — smart-routing and learning boundary discovery

- **Package:** 092 — Smart routing and learning/playbooks (PR 1)
- **Status:** in progress
- **Depends on:** 043 and 091

## Outcome

Inventory existing eligibility, budget, approval and attempt evidence contracts
and define the smallest explainable, reversible routing recommendation fixture.
It may read canonical evidence and immutable usage summaries, but cannot select
an executor, mutate a Work or Attempt, spend a budget, bypass an approval, or
turn an inferred score into authority.

## Acceptance

- Every recommendation names its immutable inputs and deterministic reason
  codes.
- Budget, scope and approval denials stay visible blockers, not weighted hints.
- Replaying identical inputs produces the same ranked candidates and no write.
- The discovery identifies a safe opt-in and rollback boundary before any route
  is served or applied.
